# 横断テーマ

複数のプロジェクト・製品に共通する設計課題を管理します。対象技術固有の構成や実装は [projects](../projects/README.md) に置き、横断レポートの正本はこの配下に一箇所だけ置きます。

| テーマ | 内容 |
|---|---|
| [TEEのライフサイクルとセキュリティ](tee-lifecycle-security/README.md) | 常駐・短命CVM、推論の状態保持、証明・鍵の寿命、失効・交換 |

新しいテーマには `<topic>/README.md` を作成し、調査レポートを `<topic>/reports/<subject>-YYYY-MM-DD.md` に配置します。参照元・検証日・対象版、確認した事実と提案・未実施試験を各レポートに記録します。
